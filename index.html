Overview

Emotion Sliv is an Android voice recorder app. The app records audio only when the user starts recording, stores recordings on the device, and may use network services for analytics, crash diagnostics, remote configuration, and user-initiated sharing.

Data categories that may be processed

  • Audio or voice recordings when the user records sound with the microphone.
  • App activity and analytics events through Firebase Analytics.
  • Crash diagnostics and technical information through Firebase Crashlytics.
  • Remote configuration data through Firebase Remote Config.
  • User-initiated shared files when the user explicitly sends a recording to Telegram.

How the data is used

  • To provide core app functionality such as recording, playback, file management, and settings.
  • To understand feature usage and improve the product through analytics.
  • To detect crashes, diagnose failures, and improve stability.
  • To enable or adjust app behavior through remote configuration.
  • To complete sharing actions explicitly requested by the user.

Third-party services

The app may send limited data to Firebase Analytics, Firebase Crashlytics, and Firebase Remote Config. If the user shares a recording to Telegram, the selected file is transferred to Telegram only as part of the user-requested action.

Permissions

  • Microphone (android.permission.RECORD_AUDIO) to record audio.
  • Internet (android.permission.INTERNET) for analytics, diagnostics, remote config, and sharing.
  • Media audio access (android.permission.READ_MEDIA_AUDIO) or legacy storage access to work with saved audio files on supported Android versions.

Retention and control

  • Audio recordings remain on the device until the user deletes them.
  • Analytics, diagnostics, and remote config retention depend on the respective Firebase service settings.
  • The user can remove recordings, revoke permissions in Android settings, or uninstall the app.

Общая информация

Emotion Sliv — это Android-приложение для записи голоса. Приложение записывает аудио только когда пользователь сам запускает запись, хранит записи на устройстве и может использовать сетевые сервисы для аналитики, диагностики сбоев, удалённой конфигурации и действий «поделиться», инициированных пользователем.

Какие категории данных могут обрабатываться

  • Аудио- или голосовые записи при записи звука с микрофона.
  • События активности в приложении и аналитика через Firebase Analytics.
  • Диагностика сбоев и техническая информация через Firebase Crashlytics.
  • Данные удалённой конфигурации через Firebase Remote Config.
  • Файлы, отправленные по инициативе пользователя при явной отправке записи в Telegram.

Как используются данные

  • Для работы основных функций приложения: запись, воспроизведение, управление файлами и настройки.

  • Для обнаружения сбоев, диагностики ошибок и повышения стабильности.
  • Для включения или настройки поведения приложения через удалённую конфигурацию.
  • Для выполнения действий «поделиться», которые явно запускает пользователь.

Сторонние сервисы

Приложение может отправлять ограниченный объём данных в Firebase Analytics, Firebase Crashlytics и Firebase Remote Config. Если пользователь отправляет запись в Telegram, выбранный файл передаётся в Telegram только в рамках действия, запрошенного пользователем.

Разрешения

  • Микрофон (android.permission.RECORD_AUDIO) для записи аудио.
  • Интернет (android.permission.INTERNET) для аналитики, диагностики, remote config и отправки.
  • Доступ к аудиофайлам (android.permission.READ_MEDIA_AUDIO) либо legacy-доступ к хранилищу для работы с сохранёнными файлами на поддерживаемых версиях Android.

Хранение и контроль

  • Аудиозаписи хранятся на устройстве до тех пор, пока пользователь их не удалит.
  • Срок хранения аналитики, диагностики и remote config зависит от настроек соответствующих сервисов Firebase.
  • Пользователь может удалить записи, отозвать разрешения в настройках Android или удалить приложение.

概述

Emotion Sliv 是一款 Android 录音应用。应用仅在用户主动开始录音时访问麦克风，录音文件保存在用户设备上。 应用还可能使用网络服务用于分析、崩溃诊断、远程配置以及用户主动发起的分享功能。

可能处理的数据类型

  • 音频或语音录音：当用户使用麦克风录音时产生。
  • 应用活动和分析事件：通过 Firebase Analytics 处理。
  • 崩溃诊断和技术信息：通过 Firebase Crashlytics 处理。
  • 远程配置数据：通过 Firebase Remote Config 处理。
  • 用户主动分享的文件：当用户明确将录音发送到 Telegram 时产生。

数据用途

  • 提供录音、播放、文件管理和设置等核心功能。
  • 通过分析了解功能使用情况并改进产品。
  • 发现崩溃、诊断故障并提升稳定性。
  • 通过远程配置启用或调整应用行为。
  • 完成用户明确请求的分享操作。

第三方服务

应用可能会向 Firebase Analytics、Firebase Crashlytics 和 Firebase Remote Config 发送有限数据。 如果用户将录音分享至 Telegram，所选文件仅会在该用户请求的分享操作中传输给 Telegram。

权限

  • 麦克风（android.permission.RECORD_AUDIO）：用于录音。
  • 网络（android.permission.INTERNET）：用于分析、诊断、远程配置和分享。
  • 音频媒体访问（android.permission.READ_MEDIA_AUDIO）或旧版存储权限：用于访问已保存的音频文件。

保存期限与用户控制

  • 录音文件会保存在用户设备上，直到用户主动删除。
  • 分析、诊断和远程配置数据的保存期限取决于相应 Firebase 服务的设置。
  • 用户可以删除录音、在 Android 设置中撤销权限，或卸载应用。
