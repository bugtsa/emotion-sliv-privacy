Политика конфиденциальности

Приложение: Freud

Package name: com.psygalaxyon.freud

Последнее обновление: 20 апреля 2026

Кратко

Это приложение позволяет записывать и прослушивать аудио на устройстве. Для работы записи требуется доступ к микрофону. Приложение также может отправлять диагностические данные (краши) и агрегированную аналитику для улучшения стабильности и качества продукта.

Какие данные могут обрабатываться

  • Аудиозаписи — если вы запускаете запись, приложение получает доступ к микрофону и сохраняет созданные записи на вашем устройстве.
  • Технические данные и диагностика — сведения о сбоях/ошибках и базовая техническая информация (например, модель устройства, версия ОС) для анализа и устранения проблем.
  • Агрегированная аналитика использования — события о том, как используются функции приложения.
  • Конфигурация приложения — приложение может получать удалённые параметры/флаги (например, через Remote Config), чтобы включать/выключать функции или менять поведение без обновления.

Как используются данные

  • Для предоставления функций приложения (запись и воспроизведение аудио, управление файлами, настройки).
  • Для повышения стабильности и качества (диагностика сбоев, улучшение производительности).
  • Для принятия продуктовых решений (обобщённая аналитика использования).

Передача данных третьим лицам

Приложение может использовать сторонние сервисы для диагностики, аналитики и конфигурации (например, продукты Firebase). Данные могут передаваться таким сервисам в объёме, необходимом для их работы.

Если вы явно инициируете действие «поделиться» (например, отправить запись в Telegram), приложение передаст выбранный вами файл в соответствующее стороннее приложение/сервис в рамках вашего запроса.

Разрешения

  • Микрофон / запись аудио (android.permission.RECORD_AUDIO) — используется только когда вы запускаете запись.

Хранение и удаление

  • Аудиозаписи хранятся на вашем устройстве до тех пор, пока вы их не удалите.
  • Срок хранения диагностических/аналитических данных зависит от настроек используемых сервисов.

Ваш выбор и контроль

  • Вы можете удалять записи в приложении или удалив данные приложения в настройках Android.
  • Вы можете запретить доступ к микрофону в настройках Android (в этом случае запись работать не будет).
  • Вы можете удалить приложение, чтобы прекратить дальнейшую обработку данных приложением.

Контакты

По вопросам конфиденциальности используйте контактные данные разработчика, указанные в карточке приложения в Google Play.
